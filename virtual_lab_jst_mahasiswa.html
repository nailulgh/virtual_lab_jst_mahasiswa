Ringkasan Rumus Algoritma JST Supervised Learning

1. Normalisasi Min-Max [0, 1]

Mencegah gradien meledak dengan memetakan setiap fitur numerik ke rentang [0, 1]:

x'ᵢ = (xᵢ - x_min) / (x_max - x_min)

2. Perceptron Learning Rule (Rosenblatt)

Menghitung y_in = b + Σ(xᵢ · wᵢ) dan menerapkan aktivasi step terhadap threshold θ. Bobot diperbarui jika terjadi error (e = t - ŷ ≠ 0):

wᵢ(baru) = wᵢ(lama) + α · (t - ŷ) · xᵢ  |  b(baru) = b(lama) + α · (t - ŷ)

3. Delta Rule / Widrow-Hoff (Least Mean Square)

Meminimalkan kuadrat error secara kontinu menggunakan selisih antara target t dan keluaran y_in:

e = t - y_in  |  wᵢ(baru) = wᵢ(lama) + α · e · xᵢ

4. Backpropagation (Multi-Layer Perceptron)

Arsitektur multilayer (Input → 3 Hidden Neurons → Output) dengan fungsi aktivasi Sigmoid kontinu f(z) = 1 / (1 + e⁻ᶻ) dan propagasi gradien error balik.

5. Hebb Rule (Bipolar Correlation)

Memetakan input dan target ke bipolar (-1 dan +1) dan memperkuat bobot saat input dan target searah.
